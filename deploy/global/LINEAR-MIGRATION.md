# Миграция Linear → Vikunja, 29 октября 2026

По запросу владельца перенесена вся команда EVG, включая историю и архив.
Команда hias-team не переносилась. В Linear ничего не изменялось.

Результат:

- 710 задач: 470 Done, 138 Canceled, 18 Duplicate, 16 In Progress, 45 Todo, 23 Backlog.
- 12 проектов Linear и отдельный проект для одной задачи без проекта.
- 106 комментариев, 982 связи, 1 685 записей истории статусов.
- Один связанный документ включён в описание задачи; семь вложений-ссылок сохранены ссылками.
- Одна архивная задача закрыта и помечена `Linear: Archived`.

## Соответствие полей

Заголовок содержит исходный номер `[EVG-N]`. Полное описание сохраняется
с Markdown → HTML преобразованием Vikunja. В конце описания записаны исходные
UUID, URL, даты создания/изменения/завершения, статус и история его переходов.

Приоритеты: None → 0, Low → 1, Medium → 2, High → 3, Urgent → 4.
Срок Linear без времени преобразован в 23:59:59 соответствующего дня Europe/Moscow;
исходная дата без времени остаётся в описании. Оценки сохранены в points
в описании и метках `Linear estimate: N points`, без пересчёта в часы.

Статусы сохранены отдельными колонками канбана. Canceled, Duplicate и архивные
задачи имеют `done=true`, чтобы не попадать в активную очередь. Это означает
закрытость, а не фактически выполненную работу; различие отмечено в описаниях,
колонках и метках. Для работы с новыми отменами следует менять и колонку, и done.

Комментарии созданы от имени владельца Vikunja; исходные автор и время указаны
в тексте. Системные created/updated/done_at назначены Vikunja при импорте.
Полного журнала всех редактирований Linear API не предоставлял: сохранены
доступные полные описания, комментарии и история статусов.

## Проверки и повторный запуск

`import_linear.py` обращается к API v2, сохраняет соответствия UUID → ID
после каждой записи и сверяет маркеры при возобновлении. POST автоматически
не повторяется после неопределённой ошибки; сначала нужно проверить результат.
Для SQLite предусмотрены повторы идемпотентных операций при временных блокировках.

`--verify-only` проверяет количество, заголовки, проекты, приоритеты, сроки,
закрытость, метки и исполнителей. `verify_linear_sqlite.py` открывает БД read-only
и дополнительно проверяет колонки всех 710 задач, метаданные истории,
106 комментариев, 982 связи и SQLite integrity_check.

Обе проверки завершились без ошибок. Во время переноса обновлений задач EVG
в Linear не обнаружено. Копии БД сделаны до и после переноса.

Приватный снимок, mapping и отчёты находятся вне Git:
`/opt/configs/vikunja/linear-migration-20261029/` на Global и в локальном
`Common/Env/apps/vikunja/linear-migration-20261029/`.
Снимок сохраняет исходные поля без преобразований. Автоматическая синхронизация
между Linear и Vikunja не настроена.
